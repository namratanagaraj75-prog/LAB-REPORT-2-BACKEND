# Backend Development Fundamentals

The three completed lab projects are grouped under `BACKEND/` so each lab remains separate and easy to run.

| Folder | Project |
| --- | --- |
| `BACKEND/lab-01/` | Node.js and Express server |
| `BACKEND/lab-02/` | SQLite database and CRUD routes |
| `BACKEND/lab-03/` | REST API, query parameters, validation, and debugging |

Each lab folder contains its own README and dependency files. Lab 3 keeps its own database and code while documenting Lab 2 as its reference project.
